# Security

Report vulnerabilities privately through a
[GitHub security advisory](https://github.com/eljoserass/scribe_eval/security/advisories/new),
not a public issue. Include the affected version or commit and steps to reproduce.
Leave out clinical or patient data.

scribe_eval is meant to run locally. Clinical datasets and runs stay on the machine
that evaluates them; only public or synthetic data may go to a remote judge.

There is no tagged release yet, so fixes land on `main`.
